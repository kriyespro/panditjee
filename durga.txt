 Online Pandit Booking Platform

## 📄 Developer Requirement Document (DRD)

---

# 1️⃣ Project Overview

Build a **multi-city marketplace platform** where:

* Users can book verified pandits
* Pandits can register & manage bookings
* Admin controls approvals, commissions & transactions
* System deducts commission automatically
* Platform scalable city-wise

Target Phase 1: Gujarat (Surat, Ahmedabad, Vadodara)

---

# 2️⃣ User Roles

### 1. Client (Customer)

### 2. Pandit (Service Provider)

### 3. Admin (Super Admin)

# 7️⃣ Booking Status Flow

```
Pending Payment
        ↓
Paid
        ↓
Accepted by Pandit
        ↓
Completed
        ↓
Reviewed
```

Cancel states:

* Cancelled by Client
* Cancelled by Pandit
* Refunded

---

# 8️⃣ Commission Logic

Example:

Booking Amount = ₹5,000
Commission = 20%

System Calculation:

* Commission = ₹1,000
* Pandit Receives = ₹4,000

Commission stored in admin revenue ledger.
