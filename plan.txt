================================================================================
  SD ONLINE PANDIT JEE — PROJECT PLAN
  Multi-City Pandit Booking Marketplace
  Target Launch: Gujarat (Surat, Ahmedabad, Vadodara)
================================================================================

TECH STACK
----------
- Backend   : Python 3.12 + Django 5
- Templates : Jinja2 (.jinja) + Django Templates (admin only)
- Frontend  : Tailwind CSS CDN + Alpine.js CDN + HTMX
- Database  : SQLite (dev) → PostgreSQL (prod)
- Payments  : Razorpay (Phase 1)
- Notifications : Email (SMTP) + SMS via Fast2SMS (MVP)
- WhatsApp  : Twilio / Meta API (Phase 2)
